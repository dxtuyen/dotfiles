# Yazi Gruvbox theme

The `theme.toml` and `gruvbox-dark.tmTheme` originate from Thomas Kopp's
[templis/yazi-gruvbox](https://git.shron.de/templis/yazi-gruvbox) project.
That theme targets Yazi 26.9 and provides a complete Gruvbox recoloring of
Yazi's preset icon table and file preview syntax highlighting.

Local adjustments keep directory names and folder glyphs in muted Gruvbox
yellow (`#d79921`), with the same accent on selected items. Other file icons
retain their semantic Gruvbox colors. The source MIT license and third-party
icon notices are kept in this directory.
